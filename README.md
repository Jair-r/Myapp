# MiPrimeraApp — React Native + Expo (JavaScript)

Proyecto de ejemplo para la Guía Práctica N.º 1 de Desarrollo de Apps Multidispositivo I.

## Requisitos
- Node.js LTS
- Visual Studio Code
- Expo Go en un teléfono Android
- Conexión a Internet

## Preparar y ejecutar
1. Instala Node.js LTS desde https://nodejs.org/
2. Abre una terminal dentro de esta carpeta.
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia Expo:
   ```bash
   npx expo start
   ```
5. Escanea el código QR desde Expo Go. Si no conecta en la red local:
   ```bash
   npx expo start --tunnel
   ```

## Imagen
La imagen de ejemplo está en `assets/icon.png`. Puedes reemplazarla por otra imagen PNG, conservando ese nombre.

## Personalización
Edita `App.js` para cambiar el nombre, carrera, colores o textos. Revisa que el botón “Probar aplicación” muestre una alerta.
